What it’s about

Products first.
Hype never.

Small tools for Linux that do one job well — made to be opened every day and kept up to date long after the first release.

01

Tools for the terminal

Live-M watches your machine, repo-doctor audits a folder of git repos, ccc queues Claude Code work, scrv keeps the screen awake. Calm, colour-coded and keyboard-friendly.

02

Light on the system

Live-M skips the process list to stay under 0.5% CPU, repo-doctor ships as a standalone binary that only needs git, and scrv is a single bash script.

03

Installable and verifiable

Signed .deb and .rpm packages from one APT/RPM repository, so updates arrive with apt upgrade. Releases carry checksums and signatures, and the source is on GitHub.
