Terminal

ccc.

A terminal home for your Claude Code work that keeps going without you.

Start conversations in any project, queue up tasks and let a background daemon work through them. It waits out usage limits and carries on by itself, asks you when Claude needs approval, commits each finished task — and can be driven from your phone with the ccc Android app.

What it does

Queue. Approve.
Walk away.

A full TUI for the work and an always-on daemon behind it. It uses your normal Claude subscription login — no API key.

Conversations

Pick a directory, tick Claude Code options (model, effort, permission mode, resume / continue / fork / from PR) and work with the real Claude Code right beside ccc’s menu. It keeps running when you close ccc.

Task queue

Queue many prompts per conversation; they run one after another in the same session. Reorder, edit, schedule (23:00, a date, or after the next usage reset) and pause.

Usage limits

Reads your real Claude usage, waits for the reset and continues by itself — with an optional reserve so automation never eats your whole limit.

Approvals

Restricted conversations (Auto-accept edits, Plan only) ask you in the TUI, on Telegram or on Discord instead of silently failing.

Routines, reviews, goals

Scheduled routines, a fresh-context reviewer that says PASS / FAIL / PARTIAL, a goal loop that works until the reviewer is satisfied, and multi-agent workflows.

Git & analytics

Each successful task is committed, with a diff viewer. Live sessions show every Claude Code session on the machine; analytics keep your token history for good.

Why ccc

Keeps working
without you.

Most terminal tools stop the moment you close them. ccc runs as a systemd --user daemon, so queued work carries on in the background, usage limits are respected automatically and you can always pick a conversation up from your phone with the Android app.

  • One ccc for every terminal — local or over SSH
  • Telegram and Discord notifications you choose per kind
  • Remote Control: drive a conversation from the Claude mobile app
  • Every keyboard shortcut can be changed, with collision checks
  • Search, Markdown export, archive and daily database backups
  • Czech and English interface

Download

Install ccc.

Needs Linux with systemd --user, Python 3.12+, the Claude Code CLI (installed and logged in) and tmux. git is optional — for auto-commit and diffs. The package adds the signed Icenux APT repository, so updates arrive with the rest of your system.

Download .deb All releases ↗
Debian / Ubuntu 
sudo curl -fsSL https://icenux.github.io/icenux/icenux.asc -o /usr/share/keyrings/icenux.asc
echo 'deb [signed-by=/usr/share/keyrings/icenux.asc] https://icenux.github.io/icenux/apt ./' | sudo tee /etc/apt/sources.list.d/icenux.list
sudo apt update && sudo apt install ccc
systemctl --user enable --now ccc ccc-tui
loginctl enable-linger "$USER"

Installs to /usr/lib/ccc and ships the systemd --user units. Your data in ~/.local/share/ccc/ is never touched.

Other ways to install

From a git checkout 
git clone https://github.com/Icenux/ccc_TUI.git ~/ccc
cd ~/ccc
bin/install.sh

Creates a virtualenv, writes the systemd --user units and starts the daemon and TUI. Options: --no-tui, --api (for the Android app), --no-start, --no-systemd.

Check that it runs 
systemctl --user status ccc ccc-tui
journalctl --user -u ccc -f
