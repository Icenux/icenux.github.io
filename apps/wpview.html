Photo viewer

wpview.

A photo viewer and editor that behaves on a touch screen, and stays out of your backend.

A standalone frontend plugin for React. wpview emits intent — rate, favorite, edit, delete — and the app that embeds it decides what happens. It has no API, no fetch and no permission logic of its own.

What it does

Everything on the photo.
Nothing on your server.

A viewer you drop into a gallery, and a clear contract between the two.

Touch first

Swipe to move through photos, pinch or double-tap to zoom, drag to pan, swipe down to close. Arrow keys and Escape work too.

Rate, favorite, tag

Optimistic updates keyed per photo, so a rating never sticks to the next one. Tags are removable chips.

Rotate and crop

Edits run in a canvas inside the viewer and arrive as a ready Blob. Animated GIFs are edited frame by frame and stay animated.

Slideshow

Fade, slide, zoom, flip or blur transitions, with timing, loop, shuffle and photo/video filters in the settings panel.

Windowed lists

Give it a window of items around the current index. At the edge it asks for more through onRequestMore.

No API, no fetch

wpview never calls a backend or applies permissions. It only emits onRate, onEdit, onDelete and friends.

The contract

You own the policy.

wpview shows only what capabilities allows, never changes the position on its own, and never confirms a delete. The full interface is documented in CONTRACT.md in the repository.

  • Controlled index and itemState
  • Callbacks: onRate, onFavorite, onTagToggle, onEdit, onDelete
  • Images and video, with a settings panel
  • Peer dependencies: react and react-dom 18
  • Playground with mock data: npm run dev
  • Tests with Vitest and Testing Library
Install

Install wpview.

wpview is not on npm yet. Add it straight from GitHub; the command is pinned to one commit, and the package builds itself on install.

Download source ZIP Repository ↗

Needs React 18 and Node.js with npm. Commit {{ app.tag | slice: 0, 7 }}.

npm 
npm install github:{{ app.repo }}#{{ app.tag }}

Then import the component and @icenux/wpview/style.css.

Use it

React 
import { WpView } from '@icenux/wpview';
import '@icenux/wpview/style.css';

<WpView
  items={items}
  index={index}
  itemState={state}
  capabilities={{ rate: true, rotate: true, crop: true }}
  onIndexChange={setIndex}
  onRate={(id, value) => api.rate(id, value)}
  onClose={() => setOpen(false)}
/>

Only the callbacks you pass are used; buttons without a matching capability stay hidden.

Good to know

Known limits.

  • Rotating re-encodes the image in a canvas, so it is lossy
  • GIFs keep at most 256 colors per frame and 1-bit transparency
  • There is no 1:1 pixel view; zoom is pinch or double-tap
  • The info panel is yours: wpview only emits onInfoOpen
  • Early version (0.1.0), the contract may still change
  • No release or license file in the repository yet
