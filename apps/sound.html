Audio tool

sound.

Your audio output, from the terminal. Speakers, monitor, Bluetooth — one keypress.

A terminal UI for PipeWire and PulseAudio: it lists every output that is connected right now, switches the default with a key and moves the apps that are already playing. Nothing changes until you press a key.

What it does

List. Switch.
Done.

It only talks to the sound server, so it does not care about your desktop: Sway, Hyprland, GNOME, KDE, X11 or Wayland.

Every output

Speakers, HDMI or DisplayPort monitors, Bluetooth and USB devices, each with its port, volume and state (muted, unplugged).

One key

Enter on the selected output, or 1–9 to jump straight to output N. Nothing happens before you press a key.

Streams follow

Apps that are already playing move to the new output instead of staying on the old one.

Never silent

The new output is unmuted on switch, so “switched” never means silence. m mutes or unmutes the selected one.

Always current

The list is re-read on start, on every keypress and every 2 seconds, so a monitor or speaker you connect while it is open simply shows up.

Scriptable

sound next and sound set hdmi work without the UI — ready for a keybinding or a status bar click.

Why not pactl

No more
sink names.

pactl set-default-sink needs the exact sink name and leaves streams that are already playing where they are, and pavucontrol is a whole mixer window for a one-key job. sound lists what is connected right now, switches the default, moves the streams and unmutes — and stays out of the way in a terminal.

  • PipeWire through pipewire-pulse, or PulseAudio
  • Needs pactl 16 or newer (JSON output), jq, bash 4+ and tput
  • Debian 12, Ubuntu 24.04 and newer ship a recent enough pactl
  • sound list marks the default output with *
  • sound set takes a number, a sink name or part of the description
  • One Bash script, no daemon, no config file

Install

Install sound.

A single Bash script. Copy it to a directory on your PATH and run sound. It needs pactl 16 or newer, jq and a running PipeWire or PulseAudio.

Keys

Controls 
up/down  select an output (also j / k)
1-9      switch to output N
Enter    switch to the selected output
m        mute / unmute the selected output
r        reload the list
q        quit

sound list            list outputs
sound next            switch to the next output
sound set hdmi        by number, name or part of the description

The default output is stored by your sound server, so your choice survives a restart. sound next makes a good keybinding.
