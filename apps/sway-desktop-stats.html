Wayland widget

Sway DesktopStats.

Conky-style desktop stats for Sway and wlroots — that actually stay behind your windows.

A second waybar instance on the bottom wlr-layer-shell layer. The Wayland protocol itself guarantees it sits beneath every normal application window, so it never floats over your work the way an XWayland Conky does.

What it shows

A quiet dashboard
for your desktop.

All panels refresh every second. Every data source is optional and degrades gracefully — a missing tool hides a row or shows a clear fallback instead of breaking the widget.

CPU temperature

Package and per-core readings from Intel coretemp, AMD k10temp or zenpower, with a thermal-zone fallback.

CPU, RAM, swap, disk

Usage bars that shift from green to orange to red as load crosses your thresholds — 60% and 85% by default.

Network at a glance

Wi-Fi SSID, local IP, public IP, Tailscale IP and live upload/download throughput, all in one block.

Top processes

The three most CPU-hungry processes on the machine, so you can spot a runaway build without opening a terminal.

Battery and uptime

Remaining time or time to full on laptops, plus a plain uptime counter for the current session.

Docker containers

A live count and list of running containers. No Docker installed? The row simply disappears.

Why this exists

Conky can't sit
behind Wayland.

Conky renders through XWayland. Under a wlroots compositor, an XWayland floating window always draws above native Wayland toplevels — no window rule can change that.

Sway Desktop Stats sidesteps the problem entirely. It is a second waybar instance running as a wlr-layer-shell surface on the bottom layer, which the protocol guarantees stays under every normal application window.

The install wiring targets Sway, but any wlroots compositor with wlr-layer-shell support can run it.

Download

Install Sway Desktop Stats.

The installer copies the panel into ~/.config/waybar/, adds a guarded launcher to ~/.config/sway/scripts/, wires it into your Sway config once, and starts the panel immediately.

Download source ZIP All releases ↗

Requires Sway or another wlroots compositor, plus waybar. Everything else is optional.

Install from source 
git clone --branch {{ app.tag }} https://github.com/Icenux/sway_desktop_stats.git
cd sway_desktop_stats
./install.sh

Remove it again with ./uninstall.sh.

Make it yours

Copy the example config 
cp ~/.config/waybar/desktop-stats.conf.example ~/.config/waybar/desktop-stats.conf
Check your output names 
swaymsg -t get_outputs

Adjust the "output" fields in desktop-stats.jsonc to match your monitors.

Remove it again 
./uninstall.sh
