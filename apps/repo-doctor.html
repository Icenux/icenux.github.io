Developer tool

repo-doctor.

A doctor for your git repositories. Audit, diagnose and safely treat them — without letting go of the wheel.

Point repo-doctor at one folder or a hundred. It scores every repository, explains each finding, and prepares fixes as reviewable commits in their own branch. Push, open a PR and merge only when you say so — and only when CI is green.

What it does

Diagnose. Treat.
Review.

A full TUI for the work, a small CLI for CI. Both run entirely offline when you want them to.

Triage, not a list

Repositories land in four bands — CRITICAL, WATCH, NO PULSE and HEALTHY — with a 0–100 score, commit pulse, git state and forge visibility.

A diagnosis per repo

The repo card explains every finding: what it means, why it matters and the exact manual steps to fix it if you prefer doing it yourself.

Safe treatment

Fixes are built in a temporary index as commits on a new repo-doctor/fixes- branch. Your working tree, index and current branch stay untouched.

Publish with guardrails

Push one fix branch, open a PR/MR on GitHub, GitLab, Gitea or Forgejo, then merge on the forge only after green CI — or fast-forward locally.

Works fully offline

Local checks need nothing but git. Network checks for OSV, PyPI, npm and forge APIs are an optional layer, never a requirement.

Also in the box

SBOM export, cleanup through the trash, fast-forward-only sync, scheduled scans, desktop/ntfy/email alerts and a read-only MCP server for AI assistants.

Why this exists

Nothing happens
by surprise.

repo-doctor is built around a simple rule: read freely, write only after an explicit preview and confirmation. Every write action is a separate step, and the state is re-checked immediately before it happens.

  • Never force-pushes or rewrites history
  • Never deletes branches, stashes or uncommitted work
  • Secrets and emails stay masked in the UI, reports, logs and MCP
  • Third-party repositories cannot execute code through hooks, filters or config
  • Network access is limited to HTTPS and SSH, with per-host HTTP opt-in
  • Only HTTPS/SSH remotes are fetched or cloned

Download

Install repo-doctor.

A standalone Linux x86_64 application. No Python runtime, no virtualenv and no npm — only git is required. The .deb and .rpm packages add the signed Icenux repository, so updates arrive with the rest of your system.

Download .deb All releases ↗

Also available as RPM, tarball and repo-doctor-bin on AUR.

Debian / Ubuntu / Mint 
wget https://github.com/Icenux/repo-doctor/releases/latest/download/repo-doctor_amd64.deb
sudo apt install ./repo-doctor_amd64.deb
repo-doctor

Other platforms and verification commands are below.

Other ways to install

Fedora · RHEL · Rocky · Alma 
sudo dnf install https://github.com/Icenux/repo-doctor/releases/latest/download/repo-doctor.x86_64.rpm
Arch Linux (AUR) 
yay -S repo-doctor-bin

Or download PKGBUILD from the latest release and run makepkg -si.

Any Linux x86_64 (no root) 
wget https://github.com/Icenux/repo-doctor/releases/latest/download/repo-doctor-linux-x86_64.tar.gz
tar xzf repo-doctor-linux-x86_64.tar.gz && ./repo-doctor/install.sh

Installs to ~/.local/lib and ~/.local/bin.
