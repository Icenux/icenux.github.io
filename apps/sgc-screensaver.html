Screensaver

SGC Screensaver.

When your Sway desktop goes idle, the Stargate Command logo takes over every screen.

A custom screensaver for Sway and wlroots that replaces the stock idle screen with a looping video of the Stargate Command logo — fullscreen on every output and synchronized across monitors. Built on mpv and swayidle.

What it does

Idle, then
on every screen.

A few small scripts and one config snippet — no daemon of its own.

Every output

The launch script starts an mpv instance on each output through swaymsg, fullscreen and in sync across monitors.

Driven by swayidle

A swayidle timeout clause starts it and its resume handler stops it, so plain mouse movement ends the screensaver.

Dismiss on input

A key press, click or scroll dismisses it through mpv-input.conf.

Its own window rule

The app ID is org.sgc.screensaver, with a dedicated for_window rule — nothing to piggyback on.

Walker aware

If Walker is installed, it is quit first so its overlay does not stay on top. Without it, that step does nothing.

Hyprland version kept

It started as an Omarchy (Hyprland) screensaver. That original lives in legacy-hyprland/ for reference.

Under the hood

Not just a port.

The Hyprland and Sway versions work quite differently. swaymsg focus output does not warp the real cursor, so the Sway version needs no IPC-socket synchronisation between instances and no cursor-position watchdog to avoid false idle-resume triggers.

Install

Install SGC Screensaver.

Clone the repository, copy two scripts and the video into place, then merge sway/sgc-idle.conf (a swayidle timeout clause and a for_window rule) into your own Sway config and run sway reload.

Download source ZIP Releases ↗

Requires Sway, mpv and jq: sudo pacman -S mpv jq.

Install from source 
git clone --branch {{ app.tag }} https://github.com/{{ app.repo }}.git
cd arch_SGC_screensaver

mkdir -p ~/.local/bin ~/.local/share/sgc-screensaver
cp local-bin/sgc-launch-screensaver ~/.local/bin/
cp local-bin/sgc-kill-screensaver ~/.local/bin/
chmod +x ~/.local/bin/sgc-launch-screensaver ~/.local/bin/sgc-kill-screensaver
cp sgc-screensaver/sgc.mp4 ~/.local/share/sgc-screensaver/
cp sgc-screensaver/mpv-input.conf ~/.local/share/sgc-screensaver/

Then merge sway/sgc-idle.conf into ~/.config/sway/config and run sway reload.

Uninstall

Remove the files 
rm ~/.local/bin/sgc-launch-screensaver ~/.local/bin/sgc-kill-screensaver
rm -rf ~/.local/share/sgc-screensaver

Then remove the timeout 150 … clause and the for_window rule from your Sway config and run sway reload.
