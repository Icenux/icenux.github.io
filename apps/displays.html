Display tool

displays.

Your external monitor layout, from the terminal. Place it, scale it, switch it on or off — with a keypress.

A terminal UI for Sway and Hyprland: extend or mirror, put the external monitor left, right, above or below the laptop, and pick a scale the compositor will actually accept. Nothing is applied until you press a key.

What it does

Place. Scale.
Keep it.

The backend is detected automatically at startup and shown in the header. Everything above it — layout math, scale snapping and the UI — is shared.

Extend or mirror

Toggle between one big desktop and a mirrored image. Mirror is available on Hyprland only — Sway cannot mirror.

Placement

Put the external monitor left, right, above or below the laptop panel. Positions are computed for you, so the layout is always anchored with no gaps.

Scale that sticks

Cycle 1 / 1.25 / 1.5 / 2, auto-snapped to the nearest value the compositor will accept for that resolution.

Outputs

Both screens, laptop only or external only. With more than one external monitor, e cycles between them.

Persistence

Your last layout survives a compositor restart and a monitor being unplugged and replugged, instead of falling back to the default rule.

Safe by default

Starting it only shows the current state. The first run wires the saved layout into your compositor config and backs the config up first.

Why not edit the config

No more
guessing numbers.

You can edit the config by hand, but you are guessing coordinates and scale values the compositor silently adjusts when they do not divide into whole pixels. displays reads the real state back from the compositor and gives instant feedback instead of a reload-and-check loop.

  • sway: swaymsg output …, saved layout included from your Sway config
  • Hyprland (Lua): Omarchy 4 “Quattro” and newer
  • Hyprland (classic): hyprland.conf with hyprctl keyword monitor
  • Sway cannot mirror — use wl-mirror next to it if you need that
  • r resets to your config defaults and forgets the saved layout
  • Only needs jq plus swaymsg or hyprctl

Install

Install displays.

A single Bash script. Copy it to a directory on your PATH and run displays. It needs jq and either swaymsg or hyprctl.

Keys

Controls 
Tab      mirror / extend
arrows   side of the external monitor
s        scale (1 / 1.25 / 1.5 / 2)
o        both / laptop only / external only
e        next external monitor
r        reset to your config defaults
q        quit

Every applied change is written to a state file that is included from your compositor config, so your last choice wins on the next start.
